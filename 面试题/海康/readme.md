# 阻止 js 默认行为
1. return  阻止代码的默认执行
2. event.preventDefault() 阻止默认行为
3. event.stopPropagation() 阻止事件冒泡
 
- js 事件流
  - 捕获阶段  -- 事件从 window 开始，一直传播到目标元素的这个过程
  - 目标阶段  -- 事件到达目标元素
  - 冒泡阶段  -- 事件从目标元素开始，一直传播到 window 的这个过程

# 闭包需要注意什么
1. 闭包会导致内存泄漏  （不能滥用，容易爆栈）

- 其他会导致内存泄漏的情况
  1. 滥用全局变量
  2. 定时器不及时清除
  3. 事件监听 不及时清除


# computed和watch的区别
1. computed 依赖的变量变更会计算一个新的值出来，这个值会被缓存，当变量变更回上一次的值时，computed 不会重新计算， watch 每次都会重新计算
