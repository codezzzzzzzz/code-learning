# 手动实现一个打包工具
 1. 实现一个打包工具，能读取我们写的高级语法，并生成浏览器能读懂的低版本语法。
 2. 借助 babel 实现代码的分析和转换    @babel/parser
   - 分析： 将代码字符串解析成 AST 语法树 （对象）
   - 依赖收集： 遍历 AST 语法树，将代码中用到的模块收集起来  @babel/traverse
   - 代码转换： 将 AST 语法树转换成浏览器能识别的代码  
      @babel/core  @babel/preset-env

   - 获取依赖：递归的方式将每一层的依赖都获取到

   - 打包：处理 require，exports 这两个关键字，最后将代码拼接起来生成浏览器能识别的完整代码


# webpack 的工作原理
通过读取入口文件内容，分析依赖，利用递归的方式将每一层的依赖都获取到，得到了整个项目的依赖关系图，针对不同类型的文件采用不用的 loader 来处理，最后基于整个依赖关系图合并生成一份完整的浏览器能识别的代码。
