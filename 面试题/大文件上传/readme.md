1. 前端读取本地文件，并做切片处理（Blob 对象的 slice方法）
2. 前端将切片处理成 FormData 对象，并做好标记
3. 前端将 FormData 对象循环发送给后端

4. 后端接收前端的 FormData 对象 （借助 multiparty 插件解析form表单数据）
5. 后端将接收到的切片文件存储到本地
6. 后端合并切片文件
 - 循环创建连续的可写流空间
 - 将切片文件读成流类型，并写入可写流空间


# 文件断点续传
 1. 当文件片段传输到一半时，暂停传输，之后又继续传输
 2. 点下继续传输按钮后，先发一个检验请求，获取后端已经很收到的文件片段信息
 3. 前端过滤掉已经传输完毕的片段，继续传输剩下的片段
